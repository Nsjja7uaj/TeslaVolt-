# TeslaVolt starter website

Responsive React + TypeScript + Vite starter.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Production files are generated in `dist/`.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## Chaport
The support buttons currently provide a copyable enquiry fallback. To enable live chat, follow Chaport's current official installation instructions and add the supplied website installation snippet to `index.html` or a dedicated React integration. Do not expose private API tokens in browser code. Test the widget on the deployed domain.

## Images
The included gallery uses illustrative Unsplash stock car images, not verified photos of the named Tesla models. Replace these with model-accurate images you have permission to use before launch.
